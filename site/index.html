What is IFC?

IFC (Industry Foundation Classes) is an open format for exchanging building information. An IFC file can describe a building as objects such as walls, windows, storeys, spaces, and their relationships. It can also hold shapes and properties.

Think of each object as a card linked to a shape. Its IFC class says what kind of object it is (IfcWall, for example); its Name is a human label; its GlobalId identifies it across exchanges. A property set groups additional named values. A field can be missing, so never treat an absent value as zero or false.

Why use it? A picture alone cannot reliably tell you which wall belongs to which storey, what an author named it, or whether a property was recorded. IFC lets different applications exchange that structured information. IFC data still needs checking: a field existing in a file does not prove the physical building is correct.

What does COMPAS IFC do?

compas_ifc is a Python library that opens an IFC file as a BuildingInformationModel. It lets us navigate the spatial hierarchy, find elements by type, name, or GlobalId, inspect properties and geometry, make changes, detect geometric overlaps, and save a new IFC file.

The library has two useful views of the data: a tree for where objects belong and a graph for relationships that are not containment. Geometry adds measurable shape; it does not replace the object's information.

We begin with a tiny public sample (sample_building.ifc) containing a wall, opening, window, and storey. The course also includes Duplex_A_20110907.ifc with several storeys and element types. Each exercise has one marked IFC_PATH line, so you can switch between them.

How to work in Binder

  1. Click Open the live notebook on the course page. Binder starts a temporary JupyterLab session in your browser.
  2. Select a code cell and press Shift + Enter. Run cells from top to bottom. Change only lines marked # CHANGE at first.
  3. The first Binder start may take several minutes. If a cell fails, read its last error line, then rerun from the top after a kernel restart.
  4. Download any IFC files you make before closing Binder. Its storage is temporary. Use the public teaching sample there; ask your instructor before uploading another model.

Run the next cell if the package is missing. Binder's course environment already includes it; the simple installation cell also lets this notebook work on another hosted Python service.

Python example Cell 2
from pathlib import Path
from compas_ifc.bim import BuildingInformationModel

IFC_PATH = Path("sample_building.ifc")  # CHANGE only when your instructor provides another IFC
if not IFC_PATH.is_file():
    raise FileNotFoundError(f"Cannot find {IFC_PATH}. Check the JupyterLab file browser.")

model = BuildingInformationModel(str(IFC_PATH), load_geometries=False, rectify_placements=False)
print("Opened:", IFC_PATH.name)
print("Model:", model.name)
model.print_hierarchy(max_depth=3)
